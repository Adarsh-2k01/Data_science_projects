# 🧠 Data-Driven Machine Learning Project for Airbnb and Customer Chrun Prediction(Regression and Classification Models)

This project demonstrates how Machine Learning can be used to solve real-world problems such as "Price Prediction" and "Customer Churn Prediction" using Python.  
It was completed as part of my Data Science & Machine Learning learning journey.

## 📌 Project A — Airbnb Price Prediction (Regression Model)

### 🎯 Objective
Build a regression model to predict the price of Airbnb listings using property features such as room type, location, amenities, reviews, host details, etc.

### 📊 Video Presentation
The video explanation link is included in the **Module 6(a)_Project.ipynb** file.

### 📘 Workflow
✔ Data Understanding & Exploration  
✔ Data Cleaning & Preprocessing  
✔ Handling missing values & outliers  
✔ Feature Engineering  
✔ Model Development  
✔ Model Evaluation (RMSE, MAE, R²)  
✔ Model Tuning  
✔ Insights & Interpretation  

### 🤖 Models Used
- Linear Regression  
- Random Forest Regressor  
- XGBoost Regressor
